# 🎯 Guild Camp System - Administrator Guide

## ภาพรวมระบบ

ระบบ Guild Camp System ออกแบบมาสำหรับจัดการกิจกรรมแคมป์เรียนด้วยระบบกิลด์ 
ผู้บริหารสามารถควบคุมและติดตามกิจกรรมทั้งหมดในเวลาจริง

---

## 📊 Admin Panel Overview

### 1️⃣ Guilds Management (🏰 กิลด์ทั้งหมด)

**ข้อมูลที่ดู:**
- ชื่อกิลด์
- ประเภท (Unity, Roblox, WebApp)
- สมาชิก
- คะแนน (Points)
- หัวกิลด์

**สิ่งที่ทำได้:**
- ปรับแต้มกิลด์ (+10, +25, -10)
- ดูความคืบหน้า
- ดูรายชื่อสมาชิก

**วิธีใช้:**
```
1. เข้า Admin → Guilds Tab
2. เลือกกิลด์ที่ต้องการ
3. คลิก +10, +25, หรือ -10
4. ดูการอัปเดตทันที
```

---

### 2️⃣ Team Management (👥 จัดการกลุ่ม)

**จุดประสงค์:**
- แบ่งสมาชิกออกเป็นกลุ่ม 3 กลุ่มต่อกิลด์
- แต่ละกลุ่ม 1-4 คน
- สามารถเป็น Unity, Roblox, หรือ WebApp

**ข้อมูลที่ดู:**
- ชื่อกลุ่ม
- จำนวนสมาชิก
- รายชื่อสมาชิก

**สิ่งที่ทำได้:**
- ดูกลุ่มของแต่ละกิลด์
- ลบกลุ่ม
- เพิ่ม/ลบสมาชิก (ผ่าน Supabase)

**วิธีใช้:**
```
1. Admin → Teams Tab
2. เลือก Guild
3. ดูรายชื่อกลุ่ม
4. ถ้าต้องลบ → คลิกปุ่ม "ลบ"
```

---

### 3️⃣ Quest Management (📜 จัดการเควส)

**ข้อมูลที่ดู:**
- ชื่อเควส
- คำอธิบาย
- แต้มรางวัล
- icon/emoji
- ส่งถึง Guild ไหน

**สิ่งที่ทำได้:**
- สร้างเควสใหม่
- กำหนดแต้ม
- เลือก Guild
- ลบเควส
- ติดตามความคืบหน้า

**ตัวอย่างเควส:**
- "เขียนโค้ด 100 บรรทัด" (50 แต้ม)
- "แก้จุดบกพร่อง 5 เรื่อง" (40 แต้ม)
- "ร่วมมติครั้งแรก" (30 แต้ม)

**วิธีใช้:**
```
1. Admin → Quests Tab
2. ใส่ชื่อเควส
3. ใส่คำอธิบาย
4. ตั้งแต้ม
5. เลือก Icon
6. เลือก Guild (หรือว่างสำหรับทุก Guild)
7. คลิก "✨ สร้างเควส"
```

---

### 4️⃣ Card Management (🃏 จัดการการ์ด)

**ระบบการ์ด:**
- 6 ชิ้นเบื้องต้น (สามารถเพิ่มได้)
- หัวกิลด์สามารถใช้ได้
- บันทึกการใช้ใน Log

**ประเภทการ์ด:**
- ⚔️ แรงปาฐาน (+30 point)
- 🛡️ โล่ป้องกัน (-20 point defense)
- ✨ เวทมนตร์ (×1.5 points)
- 💎 ทอพเพนเดิยม (+50 point)
- 🔥 ไฟประลัยพิษ (-15 point อื่น)
- 🌙 พื้นพลังจันทร์ (ถอนเควส 1)

**สิ่งที่ทำได้:**
- มอบการ์ดให้กิลด์
- ดูการ์ดทั้งหมด
- ติดตามการใช้

**วิธีใช้:**
```
1. Admin → Cards Tab
2. เลือก Guild
3. เลือก Card
4. คลิก "🎁 มอบการ์ด"
5. ดู Log เมื่อ Leader ใช้
```

---

### 5️⃣ Card Inventory - Void Management (🌀 คลังสมบัติ)

**ระบบใหม่: การ์ดสำเนา (Card Copies)**

ระบบนี้ให้ Admin จัดการการ์ดแบบเป็นสำเนาจริง ๆ พร้อมหมายเลขประจำตัว 3 หลัก
- ติดตามการ์ดทั้งหมดในระบบ
- คืนการ์ดกลับมาใช้ใหม่ได้
- ดูประวัติครบครัน

**หมายเลขการ์ด (Card Number):**
- ทั้งหมด 001-999
- ไม่ได้ซ้ำกัน
- ตัวอย่าง: 001, 002, 003, 042, 100, 999

**สิ่งที่ทำได้:**

| การทำงาน | คำอธิบาย |
|---------|---------|
| 📦 สร้างสำเนาการ์ด | สร้างการ์ดใหม่ด้วยหมายเลข 3 หลัก → เข้า Void |
| 🌀 ดูคลังสมบัติ | ดูการ์ดทั้งหมดในเก็บ (Void) |
| 🎁 มอบให้กิลด์ | เลือกการ์ดจาก Void → มอบให้กิลด์ |
| 📋 ดูสถานะทั้งหมด | ติดตามตำแหน่งการ์ดทั้งหมด |
| 🔄 คืนไปVoid | ดึงการ์ดกลับจากกิลด์ → เก็บใน Void |
| 📖 ดูประวัติ | คลิกการ์ดเพื่อดูเซลฟี่ของการเคลื่อน |

**สถานะการ์ด:**
```
✓ VOID    = อยู่ในคลังสมบัติ (พร้อมมอบได้)
🎯 GUILD  = มอบให้กิลด์แล้ว (สามารถใช้ได้)
✔️ USED   = ถูกใช้ไปแล้ว (บันทึกไว้)
```

**วิธีใช้ขั้นพื้นฐาน:**
```
1. Admin → Cards Tab
2. ดูสองส่วน:
   a) "สร้างสำเนาการ์ด" → สร้างการ์ดใหม่ หมายเลข (เช่น 001)
   b) "มอบการ์ดให้กิลด์" → เลือกจาก Void → เลือกกิลด์ → มอบ
3. ดู "🌀 คลังสมบัติ" → ดูการ์ดที่เก็บอยู่
4. ดู "📋 สถานะการ์ดทั้งหมด" → ดูทุกอย่างที่กำลังใช้งาน
```

**ตัวอย่างการใช้:**
```
Step 1: สร้างการ์ด
  - เลือก: ⚔️ แรงปาฐาน
  - หมายเลข: 001
  → ผลลัพธ์: Card #001 เข้า Void

Step 2: มอบให้กิลด์
  - เลือก: #001 - แรงปาฐาน (จาก Void)
  - กิลด์: Dragon Slayers
  → ผลลัพธ์: #001 ไปกิลด์ Dragon Slayers (🎯 GUILD)

Step 3: ใช้งาน
  - Leader ใช้การ์ด
  → ประวัติ Log: "Dragon Slayers Leader — ใช้การ์ด แรงปาฐาน"

Step 4: คืนไปVoid (Optional)
  - คลิก "🔄 คืนไปVoid" บนการ์ด
  → ผลลัพธ์: #001 กลับ Void (✓ VOID)
```

**ดูประวัติการ์ด:**
```
1. คลิกการ์ดในส่วน "🌀 คลังสมบัติ"
2. ป๊อปอัพแสดงประวัติ:
   - ชื่อการ์ด
   - หมายเลข
   - สถานะปัจจุบัน
   - ประวัติเคลื่อนไหวทั้งหมด (เมื่อ, ใคร, ทำอะไร)
```

**Troubleshooting:**

| ปัญหา | วิธีแก้ |
|-----|-------|
| หมายเลขซ้ำ | แต่ละหมายเลขต้องไม่ซ้ำ เลือกเลขใหม่ |
| หาการ์ดไม่เจอ | ตรวจสอบว่ากำหนดให้กิลด์ไหนหรือยัง |
| ต้องใช้ใหม่ | ใช้ "🔄 คืนไปVoid" ก่อน จากนั้นมอบให้อีก |

### 6️⃣ Competitions (🏁 จัดการแข่งขัน)

**จุดประสงค์:**
- สร้างการแข่งขันระหว่างกิลด์
- แข่งกันหาคะแนน
- ดูอันดับแบบ Real-time

**สิ่งที่ทำได้:**
- สร้างการแข่งขันใหม่
- ปรับแต่งคะแนน (+5, -5)
- ดูอันดับ
- ลบการแข่งขัน

**วิธีใช้:**
```
1. Admin → Competitions Tab
2. ใส่ชื่อการแข่งขัน เช่น "Coding Challenge Round 1"
3. คลิก "🏁 สร้างการแข่งขัน"
4. ปรับแต่งคะแนน (+5 หรือ -5)
5. ดูอันดับ Real-time
6. เมื่อจบสามารถลบได้
```

---

### 7️⃣ Console Log (📡 ติดตามกิจกรรม)

**ข้อมูลที่บันทึก:**
- ผู้ทำ (Actor Name)
- กิจกรรม (Action)
- เวลา (Timestamp)
- Guild (ถ้ามี)
- ข้อมูลเพิ่มเติม (เช่น ชื่อการ์ด)

**ตัวอย่าง Log:**
```
[14:23:45] สมชาย — สร้างกิลด์ "Dragon Slayers" (Unity)
[14:24:12] ปราณ — เข้าร่วมกิลด์ "Dragon Slayers"
[14:25:30] สมชาย — ใช้การ์ด "แรงปาฐาน"
[14:26:01] Admin — +25 แต้มให้กิลด์ id=1
```

**วิธีใช้:**
```
1. Admin → Console Log Tab
2. ดูกิจกรรมล่าสุด (บนสุด)
3. ลงเลื่อนดูประวัติเก่า
4. คลิก "↻ รีเฟรช" เพื่ออัปเดตล่าสุด
```

## 🎯 Workflow Example

### วิธีจัดกิจกรรมแคมป์

**วันที่ 1 - Setup**
```
1. สร้างกิลด์ 3 กิลด์
2. เพิ่มสมาชิก
3. สร้างกลุ่มสำหรับแต่ละกิลด์
4. สร้างเควสแรก
```

**วันที่ 2-3 - Quests**
```
1. เพิ่มเควสใหม่ทีละวัน
2. ปรับแต้มตามประเมิน
3. ติดตามใน Admin Log
```

**วันสุดท้าย - Competitions**
```
1. สร้างการแข่งขันสุดท้าย
2. มอบการ์ดพิเศษ
3. ปรับแต้มตัดสินใจ
4. ประกาศผล
```

## ⚠️ Troubleshooting

### ปัญหา: ไม่เห็นข้อมูล
**วิธีแก้:**
- Refresh หน้า (F5)
- ตรวจสอบ Supabase connection
- ดู Browser Console (F12)

### ปัญหา: Admin password ไม่ได้
**วิธีแก้:**
- ตรวจสอบตัวพิมพ์ (case-sensitive)
- Default: `camp2025`
- Refresh หน้า

### ปัญหา: ไม่เห็น Guild
**วิธีแก้:**
- ตรวจสอบว่าสมาชิกเข้าร่วมแล้ว
- Refresh หน้า
- ดูใน Supabase dashboard

### ปัญหา: Card ไม่เห็นแล้ว
**วิธีแก้:**
- ค้นหา `initSystemCards()` ใน code
- Refresh Admin login
- ตรวจสอบ cards table

## 🚀 Tips & Tricks

1. **ปรับแต้มแบบสมดุล**
   - ใช้ +10 สำหรับความเห็นดี
   - ใช้ +25 สำหรับอย่างยอดเยี่ยม
   - ใช้ -10 สำหรับลงโทษเล็กน้อย

2. **เควสที่ดี**
   - ตั้งชัดเจน
   - ให้แต้มเป็นธรรม
   - ส่งให้กิลด์เฉพาะ หรือ ทุกกิลด์

3. **การ์ดพิเศษ**
   - มอบให้เฉพาะ leader
   - บันทึกการใช้ทั้งหมด
   - ใช้เพื่อเพิ่มความสนุก

4. **ประมวลผล**
   - ดูทุก log
   - ตัดสินใจแบบยุติธรรม
   - ประกาศผล Clear
